Database

The same tables the deployed system runs on

SELECT id, command, status, exit_code, submitted_at, completed_at FROM commands ORDER BY id DESC

fork_session() rebuilds an environment from a command's cwd_snapshot/env_snapshot; replay_session() re-queues the session's original commands under one replay_run_id.

Queries run against the same database the shell uses. ⌘/Ctrl+Enter runs.

This page is a complete pg_shell instance. PostgreSQL runs in your browser through PGlite, and the schema, RPCs and HTML fragments come from this repository's sql/ directory, unmodified. The one part that cannot be real in a browser tab is the executor: a tab has no processes, so commands run against an in-memory filesystem from a fixed allowlist rather than through workers/executor_agent.py.
